## 1. O(1) — Constant Time
Accessing `nums[0]` takes constant time, regardless of the list size.

## 2. O(n) — Linear Time
Checking every element in a list takes time proportional to the number of elements.

## Linear Search
Linear Search checks elements one by one until the target is found. In the worst case, it checks every element, so its time complexity is O(n).
